คู่มือการใช้งาน Print Bridge

เวอร์ชัน 1.0 · สำหรับ Windows

การติดตั้ง
1
ดาวน์โหลดและรัน Installer ดาวน์โหลดไฟล์ Print Bridge Setup.exe แล้วดับเบิลคลิกเพื่อติดตั้ง
2
โปรแกรมจะเปิดหน้าตั้งค่าอัตโนมัติ ครั้งแรกที่รันจะมีหน้าต่างขอ Bridge Code ปรากฏขึ้น
3
คัดลอก Bridge Code จากระบบร้านอาหาร เข้าระบบ → หน้า เครื่องปริ้น → กดปุ่ม คัดลอก Bridge Code
4
วาง Code แล้วกด "บันทึกและเชื่อมต่อ" โปรแกรมจะเชื่อมต่อและหุบตัวไปอยู่ใน System Tray (มุมขวาล่าง)
สัญลักษณ์ใน System Tray
วงกลมเขียว เชื่อมต่อแล้ว พร้อมปริ้น
วงกลมแดง ไม่ได้เชื่อมต่อ — ตรวจสอบอินเทอร์เน็ต
วงกลมเหลือง กำลังเริ่มต้นโปรแกรม
การใช้งานประจำวัน
เปิดอัตโนมัติเมื่อเปิด Windows
โปรแกรมตั้งค่า Auto-start ไว้แล้ว ไม่ต้องรันเองทุกวัน
คลิกขวาที่ไอคอนเพื่อ
ดูสถานะ · เปิดหน้าตั้งค่า · เชื่อมต่อใหม่ · ปิดโปรแกรม
ดับเบิลคลิกที่ไอคอน
เปิดหน้าตั้งค่าขึ้นมาทันที
กรณีต้องตั้งค่าใหม่ (เปลี่ยนร้าน / token หมดอายุ)
1
คลิกขวาที่ไอคอนใน System Tray แล้วเลือก ตั้งค่า...
2
คัดลอก Bridge Code ใหม่จากระบบ เข้าระบบด้วย account ของร้าน → หน้าเครื่องปริ้น → คัดลอก Bridge Code
3
วาง Code แล้วกด "บันทึกและเชื่อมต่อ" ไอคอนจะเปลี่ยนเป็นสีเขียวเมื่อเชื่อมต่อสำเร็จ
การแก้ปัญหาเบื้องต้น
ไอคอนแดงตลอด ทั้งที่อินเทอร์เน็ตปกติ
คลิกขวา → เชื่อมต่อใหม่ หรือคัดลอก Bridge Code ใหม่แล้วตั้งค่าใหม่อีกครั้ง
ปริ้นไม่ออกทั้งที่ Bridge เขียว
ตรวจสอบว่าเครื่องปริ้นและคอมพิวเตอร์อยู่ใน WiFi วง LAN เดียวกัน
ไม่เห็นไอคอนใน System Tray
คลิกลูกศร ^ ที่มุมขวาล่างของ Taskbar เพื่อดูไอคอนที่ซ่อนอยู่
ต้องการถอนการติดตั้ง
Settings → Apps → ค้นหา "Print Bridge" → Uninstall
